# 👹 MirTimeBoss v1.0.0

**Система автоматических мировых боссов с уникальными способностями, босс-баром, топом по нанесённому урону и настраиваемым лутом** для серверов Minecraft (**Paper / Purpur 1.21+**), разработанная для проекта **Mir-Time**.

---

## 🌟 Основные возможности

### 1. Автоматический спавн по расписанию и анонсы
* Спавн боссов на заданных координатах через равные промежутки времени или по расписанию из `config.yml`.
* Яркие широковещательные оповещения в чат с координатами появления босса и звуковым сигналом для всех игроков онлайн.
* Информативный **BossBar** с отображением имени босса, текущего здоровья в реальном времени и цвета полосы.

### 2. Уникальные боевые механики и способности
* Настраиваемые характеристики каждого босса: запас здоровья (HP), скорость передвижения, урон, броня и кастомная экипировка.
* Специальные атаки в бою: отбрасывание игроков ударной волной, наложение негативных эффектов, призыв миньонов-защитников и удары молнией.

### 3. Система топа по урону и распределение наград
* Точный подсчёт урона, нанесённого каждым игроком за время сражения с боссом.
* После победы над боссом в чат выводится **Топ-3 лучших бойцов** с количеством нанесённого урона.
* Автоматическая выдача наград (предметов, валюты через Vault или донат-кейсов) за призовые места и выпадение лута.

## ⌨️ Команды и права (Permissions)

| Команда | Алиасы | Описание | Право |
| :--- | :--- | :--- | :--- |
| `/mtboss spawn <босс>` | `/boss spawn` | Принудительно заспавнить выбранного босса | `mirtime.boss.spawn` |
| `/mtboss killall` | `/boss killall` | Удалить всех активных боссов на сервере | `mirtime.boss.kill` |
| `/mtboss setspawn <босс>` | `/boss setspawn` | Установить точку появления босса на текущих координатах | `mirtime.boss.admin` |
| `/mtboss info` | `/boss` | Узнать время до следующего появления босса и координаты | Доступно всем |
| `/mtboss reload` | — | Перезагрузить `config.yml` без перезапуска сервера | `mirtime.boss.reload` |

## 📦 Установка

1. **Скачайте плагин из раздела Releases:**
   * Перейдите во вкладку **[Releases](../../releases)** в правой части страницы репозитория.
   * Выберите последний актуальный выпуск (например, `v1.0.0`).
   * В блоке **Assets** нажмите на файл `MirTimeBoss-1.0.0.jar`, чтобы скачать его.
2. **Установите на сервер:**
   * Загрузите скачанный `.jar`-файл в папку `/plugins/` вашего сервера (**Paper / Purpur 1.21+**).
   * *(Опционально)* Установите **Vault** и **PlaceholderAPI**, если планируете выдавать денежные награды за убийство боссов или выводить таймер в скорборд.
3. **Запустите и настройте:**
   * Перезапустите сервер, задайте координаты спавна командой `/mtboss setspawn <босс>`, настройте здоровье и награды в `plugins/MirTimeBoss/config.yml` и выполните `/mtboss reload`.
