# 👹 MirTimeBoss v1.0.0

**Автоматическая система боссов для Арены Смерти** с ротацией 5 уникальных противников, динамической шкалой `BossBar`, защитой построек и распределением наград по топ-урону (**Paper / Purpur 1.21+**).

---

## 🌟 Основные возможности

### 1. Ротация 5 уникальных боссов
Каждый час (настраивается) на заданной точке Арены Смерти появляется новый босс со своими характеристиками и способностями:
1. **🕷 Королева Пауков (`500 HP`)** — накладывает на игроков вокруг эффекты *Отравления II* и *Замедления II*.
2. **💀 Некромант Арены (`650 HP`)** — периодически призывает себе на помощь миньонов-скелетов.
3. **🐗 Бешеный Разрушитель (`800 HP`)** — подбрасывает противников высоко в воздух мощным ударом.
4. **🔥 Огненный Пиглин-Берсерк (`950 HP`)** — поджигает всех игроков в радиусе 7 блоков вокруг себя.
5. **👁 Древний Хранитель Бездны (`1024 HP`)** — накладывает эффект *Тьмы* и приносит самые ценные награды (включая *Пламенный Тотем Призыва*).

### 2. Умный контроль онлайна и бездействия
* **Проверка минимального онлайна (`min-online: 2`):** автоматический спавн по таймеру срабатывает только тогда, когда на сервере достаточно игроков для PvP-сражения.
* **Таймер бездействия (`idle-despawn-seconds: 60`):** если после появления или последнего удара боссу никто не наносит урон в течение **60 секунд**, он автоматически исчезает с арены без выпадения наград.
* **Защита ландшафта:** боссы не могут ломать или изменять блоки на арене.

### 3. Динамический `BossBar` и система наград Топ-3
* Сверху экрана у всех игроков отображается шкала здоровья активного босса с точным остатком HP.
* Плагин подсчитывает урон каждого игрока и после смерти босса автоматически награждает **3 лучших бойцов** (выполняя любые консольные команды из `config.yml`).

## ⚙️ Гибкая настройка (`config.yml`)
Вы можете легко менять мир спавна, координаты, имена боссов, их здоровье (до `1024.0` под стандартный лимит `spigot.yml`) и команды наград:
```yaml
spawn:
  world: "game"
  x: -192.5
  y: 74.0
  z: 103.5

spawn-interval-minutes: 60
min-online: 2
idle-despawn-seconds: 60
```

## ⌨️ Команды и права (Permissions)

| Команда | Описание | Право |
| :--- | :--- | :--- |
| `/boss setspawn` | Установить точку появления боссов на вашей позиции | `mirtime.boss.admin` |
| `/boss start [босс]` | Запустить спавн следующего или конкретного босса вручную | `mirtime.boss.admin` |
| `/boss stop` | Принудительно удалить активного босса с арены | `mirtime.boss.admin` |
| `/boss reload` | Перезагрузить `config.yml` | `mirtime.boss.admin` |

## 📦 Установка
1. Скачайте `MirTimeBoss-1.0.0.jar` из вкладки **Actions**.
2. Закиньте файл в папку `plugins/` и перезапустите сервер.
3. Убедитесь, что в регионе арены (**WorldGuard**) разрешены флаги `mob-spawning: allow` и `mob-damage: allow`.
4. Встаньте в центр арены и пропишите `/boss setspawn` (или укажите координаты в `config.yml`).
